Known discrepancies / limits
----------------------------
- en_texts.xml / ru_texts.xml: C# tree replaced Java-style `%s` with .NET `{0}`
  format placeholders in several RS strings (trade/teach/raven/tools). DBs and
  dialog XML remain byte-identical. ab-diff records this as KNOWN_DIFF (non-fatal).
- Java getSaveFile() embeds a Windows-style path separator in the string
  (…\\save/rgame_N.rgp). C# uses Path.Combine (Linux-safe). Saves themselves
  use the same RGP/RGT/RGJ layout and RGF 1.21 — cousins, not bit-identical worlds.
- Worldgen / RNG differ (Java threading vs C#); same seed ≠ same map.
- Full Oldman/DemonBane quest still needs manual play in both (table above).
- Do not commit nwr-dist-v0.11.0-win/ (gitignored); fetch script is the source.
