## Description
Set up the Mono + SDL2 development environment to build and run the C# port of NorseWorld: Ragnarok from source.

## Requirements
- `mono-complete` (mono-devel + mono-mcs)
- `libsdl2-mixer-2.0-0`
- `libsdl2-image-2.0-0`
- `git` (for cloning sibling libs BSLib and ZRLib)

## Implementation
1. Install system packages
2. Run `./play-cs.sh` end-to-end. This script handles:
   - Cloning sibling repos (BSLib, ZRLib) via `git clone --depth 1`
   - Running `xbuild NWR.sln /p:Configuration=Release`
   - Staging NVorbis dependencies and sound packs
3. Verify `project/bin/Release/NWR.exe` exists
4. Verify `mono NWR.exe` starts (may fail on missing resources — that's fine)

## Acceptance Criteria
- [ ] `./play-cs.sh` builds successfully with exit code 0
- [ ] `project/bin/Release/NWR.exe` exists and is executable via mono
- [ ] `mono NWR.exe` doesn't produce assembly resolution errors
- [ ] System dependencies (`libsdl2-mixer-2.0-0`) are installed

## Notes
- Target framework: .NET 4.5.2, well-supported by Mono 6+
- `AllowUnsafeBlocks=True` in .csproj — expected for SDL2 interop
- If `xbuild` is deprecated on the target system, try `msbuild` (from mono-devel)
- The repo root is where `play-cs.sh` lives — the build copies `NWR.exe` there
