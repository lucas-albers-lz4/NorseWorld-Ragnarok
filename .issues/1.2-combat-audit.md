## Description
`NWCreature.cs` (4400 lines) contains the entire combat pipeline. This is the most game-mechanic-dense file and the most likely source of gameplay bugs. Audit the attack, damage, and defense resolution system.

## Scope

### Attack resolution
- `DoAttack()` — main attack method
- `GetAttack()` — calculates attack roll
- `CalcDamage()` — damage calculation with weapon/skill/strength modifiers
- `GetDamage()` — final damage with resistances
- `Damage()` — applies damage to target
- Attack type dispatch: melee, ranged, thrown

### Defense
- `ArmorClass` — how AC reduces hit chance (manual says "lower = better", verify)
- `Parry` — parry chance calculation
- Dodge/evasion logic

### Death
- `Die()` — death handling, corpsification, item drops
- `Kill()` — killing blow logic
- Corpse generation
- Experience reward calculation

### Movement & Speed
- `Speed` / `SpeedMod` — turn ordering (manual: "10 is normal for humans")
- `Movements` property — movement capabilities
- `CanMove()` — movement validation

### Statistics
- HP: `HPCur`, `HPMax_Renamed` — bounds checking
- Strength: default values, modifiers
- `Constitution` — healing rate, toxin resistance
- `Attacks` — number of attacks per turn

## Method
1. Trace one complete combat cycle: player attacks creature → hit check → damage calc → damage application → creature response
2. Document the call graph
3. Check for: integer overflow, negative damage, AC inversion, null dereferences through `CurrentField`/`FindCreature`/`Entry`

## Acceptance Criteria
- [ ] Complete combat call graph documented
- [ ] No integer overflow paths (or documented and deferred)
- [ ] AC comparison direction verified against manual ("lower = better, 10 is normal")
- [ ] Death/disposal path reviewed for null refs
- [ ] Bug issues filed for any discovered issues

## Cross-Reference
