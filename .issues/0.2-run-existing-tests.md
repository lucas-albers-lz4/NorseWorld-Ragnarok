## Description
Build and run both `NWR.Tests` (NUnit) and `NWR.Harness` (standalone exe) to establish the regression baseline. Document which scenarios pass, which fail, and what the failure signatures look like.

## Implementation
1. Build the solution (should already be done from Issue 0.1)
2. Locate `NWR.Tests.exe` and `NWR.Harness.exe`
3. Run unit tests: `mono NWR.Tests.exe`
4. Run integration scenarios: `mono NWR.Tests.exe --all`
5. Run harness scenarios: `mono NWR.Harness.exe --all`
6. Run `./dev_info/run-tests.sh` (the canonical test runner)
7. Save results to `dev_info/test-results/baseline-YYYY-MM-DD.log`

## Existing Scenarios
- `bootstrap-check` — verifies NWGameSpace initializes
- `save-load-roundtrip` — load fixture → snapshot → save → load → snapshot match
- `save-overwrite` — load → save twice, check no log failures
- `save-erase` — load → erase → verify files gone
- `player-metadata` — LoadPlayer preview path
- `container-roundtrip` — container fixture save/load item count
- `effect-persist` — effects fixture save/load count
- `wait-turns` — caWait + ProcessGameStep loop
- `item-use-potion` — spawn Potion_Curing, UseItem, verify HP increases
- `teleport-trap` — move player onto teleport trap, verify relocation

## Acceptance Criteria
- [ ] NUnit tests execute and report pass/fail per test
- [ ] Integration scenarios pass (or failures are documented as known bugs)
- [ ] Test results are saved to a timestamped baseline file
- [ ] Any test failure that is a pre-existing bug (not environment issue) is assigned its own bug issue

## Known Issues (from dev_info/follow-ups.txt)
- Quit-time logged exceptions on exit (ProwlingEnd, EffectsList)
- BaseMainWindow.run(): "Method has zero rva" on Mono startup (benign?)
- The `--all` mode excludes build-* scenarios (intentional — they write files)

## Notes
- Log failure patterns checked by LogAssert: `saveGame.IO()`, `loadGame():`, `terrainsLoad(): fail`, `playerLoad(): fail`, `Critical error`
- Use `./dev_info/triage-failure.sh SCENARIO_NAME` to package failures for review
